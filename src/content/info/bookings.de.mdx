# Termine

Du kannst auf deinem Profil einen Button oder eine Karte anzeigen, womit Besucher über den von dir genutzten Kalenderdienst einen Termin mit dir vereinbaren können.

## So funktioniert es

1. Erstelle in deinem eigenen Kalenderdienst einen Buchungslink.
2. Füge diesen Link als Karte oder Button im Studio hinzu.
3. Besucher buchen direkt über diesen Dienst; die Bestätigung kommt von diesem Dienst.

## Gut zu wissen

ROUT speichert keine Termine oder Daten der Personen, die buchen. Verfügbarkeit, Erinnerungen und Stornierungen verwaltest du in deinem Kalenderdienst.
