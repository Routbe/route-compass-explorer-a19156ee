# Wallet

Une carte ou un pass dans Apple Wallet ou Google Wallet est un support d'informations pratique. Il ne s'agit pas automatiquement d'une pièce d'identité officielle.

## Pass d'accès ou carte de profil

Un pass d'événement peut attester d'un accès ou d'une participation à un événement. Une carte de profil peut renvoyer vers votre profil ROUT. L'émetteur et le contrôle effectué lors de l'utilisation déterminent ce que le pass prouve réellement.

| Pass | Signification | Aucune garantie automatique |
| --- | --- | --- |
| Pass d'événement | Référence à un accès ou une participation | Acceptation par chaque organisateur |
| Carte de profil | Référence à un profil ROUT | Pièce d'identité légale |
| Credential externe | Déclaration d'un émetteur | Approbation par Apple, Google ou ROUT |

## Apple et Google

Les pass Apple nécessitent des certificats de signature valides. Google Wallet requiert un émetteur configuré ainsi que des identifiants de service valides. Si cette configuration est manquante, l'ajout n'est pas disponible ; une charge utile (payload) d'exemple ne constitue pas un pass signé utilisable.

## Visibilité et actualité

Vérifiez quelles informations figurent sur le pass et si le profil associé peut être public. Un pass enregistré peut afficher un état antérieur. Un code scanné doit donc renvoyer vers une destination qui contrôle les droits en temps réel.

## En cas de perte ou de modification

Supprimez un pass indésirable via votre application Wallet. Cela ne supprime pas automatiquement votre compte ROUT ni l'attestation délivrée par l'émetteur. Gérez ces éléments séparément dans ROUT ou auprès de l'organisateur concerné.
