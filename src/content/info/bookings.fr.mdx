# Rendez-vous

Vous pouvez afficher un bouton ou une carte sur votre profil permettant aux visiteurs de planifier un créneau avec vous via le service d'agenda que vous utilisez.

## Comment cela fonctionne

1. Créez un lien de réservation dans votre propre service d'agenda.
2. Ajoutez ce lien sous forme de carte ou de bouton dans le Studio.
3. Les visiteurs planifient directement auprès de ce service ; la confirmation provient de ce service.

## Bon à savoir

ROUT ne conserve aucun rendez-vous ni aucune coordonnée des personnes qui réservent. Vous gérez les disponibilités, les rappels et les annulations directement dans votre service d'agenda.
