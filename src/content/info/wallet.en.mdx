# Wallet

A pass in Apple Wallet or Google Wallet is a handy carrier of information. It isn't automatically an official identity document.

## Access pass or profile card

An event pass can reflect access or participation in an event. A profile card can link to your ROUT profile. The issuer and the verification check upon use determine what a pass actually proves.

| Pass | Meaning | No automatic guarantee |
| --- | --- | --- |
| Event pass | Reference to access or participation | Acceptance by every organizer |
| Profile card | Reference to a ROUT profile | Legal identity document |
| External credential | Statement from an issuer | Endorsement by Apple, Google, or ROUT |

## Apple and Google

Apple passes require valid signing certificates. Google Wallet requires a configured issuer and valid service credentials. If that configuration is missing, adding passes is unavailable; a preview payload isn't a usable signed pass.

## Visibility and freshness

Check what information appears on the pass and whether the linked profile should be public. A saved pass might show an earlier state. Therefore, a scanned code should point to a destination that verifies current permissions.

## In case of loss or changes

Remove an unwanted pass via your Wallet app. This doesn't automatically delete your ROUT account or the issuer's statement. Manage those separately in ROUT or with the relevant organizer.
